# Sharp_-_MZ-2000

Thumbnails for Sharp MZ-2000 software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails) (`Named_Snaps`), named after the MAME short names of its software lists.

The snaps were taken with the MAME libretro core in RetroArch: each tape is loaded from the IPL (C) and each floppy booted, and MAME takes a snapshot every 300 frames from frame 900 to 2700; the one with the most colours is kept, at twice the machine's height. Programs that stayed on a DOS prompt or blank have no snap.
